# Битрикс24: отчёт по выбранному сотруднику

**[Скачать приложение для Windows — ZIP](https://github.com/samogt/jdnsd/raw/refs/heads/main/bitrix24-audit/bitrix24_gui.zip)**

1. Скачайте и полностью распакуйте архив.
2. Дважды нажмите **START_GUI.cmd**.
3. Введите вебхук, загрузите список и выберите сотрудника. По умолчанию никто не выбран; можно явно ввести ID.
4. Укажите период и папку, нажмите **«Сформировать отчёт»**.
5. Получите результат и откройте таблицу или CSV для Excel.

Приложение последовательно показывает **параметры → формирование → результат**. По умолчанию выбран период последних двух календарных месяцев. Готовый отчёт содержит дату, время, действие, объект, подтверждение и ссылки на сохранённые JSON-ответы.

Работает локально в Windows с Windows PowerShell 5.1 и WPF. Устанавливать сервер, Python, Node.js или сторонние модули не нужно. Вебхук вводится в приложении; в архиве нет рабочих токенов и выгрузок портала.

- [Подробная инструкция по интерфейсу](README_GUI_RU.txt)
- [Источники данных, права, ограничения и документация сборщика](README_COLLECTOR_RU.md)

Для списка сотрудников нужен один из scopes `user`, `user_basic`, `user_brief`. Для всех источников сбора: `main`, `task`, `crm`, `disk`, `timeman`, `telephony`, `bizproc`. Доступность данных зависит от прав владельца вебхука, тарифа и сохранности журналов.

Поддерживаются остановка с частичным отчётом, продолжение по сохранённым страницам и пересборка без сети. Сборщик использует методы чтения; настройки и данные портала не изменяет.

Логика проверена в PowerShell 7.4.13 на Linux на синтетических данных, включая запуск дочернего процесса, выбор сотрудника, пагинацию, остановку и восстановление. Фактическое отображение WPF-окна на Windows и подключение к пользовательскому порталу в этой среде не проверялись.
