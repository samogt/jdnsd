Для кого нужен отчёт?

По умолчанию никто не выбран. Период — последние два календарных месяца.

Вебхук хранится только в памяти работающего приложения. После перезапуска для продолжения его нужно ввести снова.

Период событий

Фиксированное смещение применяется к отображению и датам без часового пояса.

Источники

Полный поиск может быть длительным: для части методов нужны существующие задачи, карточки и папки. Источники работают независимо; отчёт доступен сразу и обновляется по мере ответов. Число запросов не равно числу действий сотрудника.
